Solución Definitiva para "Invalid credentials"

El error "Invalid credentials" en Producción significa que estás usando las credenciales de QA/Sandbox en el ambiente de Producción.

¡VERIFICA ESTO PRIMERO!

PayU SIEMPRE tiene credenciales separadas para QA y Producción.

Si alguien te dijo que son las mismas, está INCORRECTO.

Pasos para Obtener Credenciales Correctas:
  1. Accede al dashboard de Producción:
    • URL: https://dashboard.payulatam.com/
    • Inicia sesión con tus credenciales de Producción
  2. Obtén las credenciales API de Producción:
    • Ve a Configuración → API Keys
    • Busca las credenciales marcadas como "Producción"
    • Copia el API Login y API Key
  3. Configúralas en este sistema:
    • En la pestaña "Configuración"
    • En los campos "API Login (Producción)" y "API Key (Producción)"
  4. Prueba nuevamente:
    • Usa el botón "Probar Conexión Actual"
    • O "Probar Ambos Ambientes" para verificar ambos
¿Por qué pasa esto?
  • PayU genera credenciales ÚNICAS para cada ambiente
  • Las credenciales de QA/Sandbox NO FUNCIONAN en Producción
  • Las credenciales de Producción NO FUNCIONAN en QA
  • Son sistemas COMPLETAMENTE SEPARADOS
